# Replify AI 🚀

Replify AI is an AI-powered conversation analysis and smart reply generator that helps users understand chat sentiment and craft better responses.

## Features

* Analyze conversation emotion
* Detect conversation health score
* Estimate misunderstanding risk
* Generate AI-powered replies in multiple styles:

  * Friendly
  * Supportive
  * Funny
  * Professional
  * Confident
  * Flirty
  * Formal
  * Apologetic
  * Motivational
* Communication improvement tips
* One-click copy functionality
* Modern responsive UI

## Tech Stack

### Frontend

* React.js
* Vite
* CSS

### Backend

* FastAPI
* Python

### AI

* GPT OSS 120B (via API)

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
